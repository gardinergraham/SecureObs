What managers need to know

Staff and access

Add permanent staff, agency/bank staff, PIN access, role permissions and NFC identifiers.

Ward setup

Governance

Manager route

Sign in with manager access

Use NFC or STAFFCODE/PIN and confirm the correct site and ward before making any setup changes.

Open settings

Review the ward identity, observation interval, session timeout and enabled feature modules.

Add or update staff

Set role, ward access, prescribing permission if appropriate, active status and NFC tag details.

Configure rota and shift cover

Assign nurse in charge, medication nurse and enhanced observation cover so the ward knows who owns each task.

Monitor sync and safety

Check any queued uploads, review unresolved incidents and make sure staff understand the local escalation route.

Feature switches explain what staff can see

SecureObs can be made as focused or as fully featured as the site needs. If a feature is off, staff should understand that it has been disabled for that ward, not that the app is broken.

  • Turn on only the modules needed by the ward.
  • Keep session expiry aligned with local governance.
  • Check staff role permissions before giving access.
  • Use the NFC tag writer when issuing permanent staff tags.

Manager safety reminders

Do not give staff access under another person’s login or role.
If sync issues remain unresolved, treat this as an operational risk and escalate.
